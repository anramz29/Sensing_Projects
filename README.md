# Sensing Projects

ROS2 labs and projects for sensing systems, including GPS, IMU, and GNSS drivers built with Python and ROS2 Humble.

## Structure

```
.
├── LAB0/          # ROS2 publisher/subscriber basics (simple_chatter)
├── LAB1/          # GPS driver and data analysis
├── LAB3/          # IMU driver and data analysis
└── gnss/          # RTK GNSS driver and analysis
```

## Labs

### LAB0 — ROS2 Basics
Introduction to ROS2 with a simple publisher/subscriber node.

### LAB1 — GPS Driver
Custom ROS2 GPS driver (`gps_driver`) with rosbag data collection and Jupyter notebook analysis.

### LAB3 — IMU Driver
Custom ROS2 IMU driver (`imu_driver`) with bag recording script and Jupyter notebook analysis.

### GNSS — RTK Driver
RTK GNSS driver (`rtk_driver`) with data analysis notebook and lab report.

## Dependencies

- ROS2 Humble
- Python 3
- Jupyter Notebook
